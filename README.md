# AFFOTECH Supervisor Orchestrator Evidence

Private GitHub evidence relay foundation. Immutable terminal publications are separate from mutable current indexes and Architect acceptance pointers. Initial state contains no fabricated terminal or acceptance record.

## Governing entrypoints

- [`governance/ORCHESTRATOR_BOOTSTRAP.md`](governance/ORCHESTRATOR_BOOTSTRAP.md) — canonical project-independent governance kernel for reusable governed projects.
- [`governance/PROJECT_ORCHESTRATION_POLICY.md`](governance/PROJECT_ORCHESTRATION_POLICY.md) — AFFOTECH Agent Orchestrator-specific extension of that kernel.

The universal bootstrap may be pinned/vendored into new governed application projects together with a project-owned `PROJECT_ORCHESTRATION_POLICY.md`. Project policy may strengthen the bootstrap but must not silently weaken it.

Machine workflow authority remains in the durable evidence/decision/prompt/dispatch/result chain. Human-readable Drive mirrors and documentation do not replace GitHub machine authority.
