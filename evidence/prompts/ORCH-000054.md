MUTATION LEASE DESIGN

A. RECORD TYPE / PROTOCOL

B. IMMUTABLE RECORD FIELDS
Define an exact supported v1.0 top-level schema containing at minimum:
- recordType
- schemaVersion
- protocolFamily
- leaseId
- leaseRevision
- leaseEpoch
- projectId
- resourceScope
- resourceScopeSha256
- mutationEnvelopeSha256
- holder
- messageId
- dispatchId
- milestoneId
- state
- acquiredAt
- expiresAt
- releasedAt
- previousRecordSha256
- releasedBy

Rules:
- leaseId uses MUTATION-LEASE-* shape.
- leaseRevision integer >=1.
- leaseEpoch integer >=1.
- initial revision requires previousRecordSha256=null.
- later revisions require lowercase 64-hex previousRecordSha256.
- resourceScope is a non-empty bounded array of canonical resource strings; reject "*" / all-project / unbounded forms.
- resourceScopeSha256 is caller-supplied deterministic lowercase 64-hex identity for the normalized exact scope.
- mutationEnvelopeSha256 is lowercase 64-hex.
- holder binds exact registrationId and workerRole.
- messageId/dispatchId/milestoneId are non-empty and bind the lease to one governed operation lineage.

C. STATE / TIME MODEL
Support:
- ACTIVE
- RELEASED
- EXPIRED

Rules:
- acquiredAt integer epoch milliseconds.
- expiresAt integer epoch milliseconds > acquiredAt.
- ACTIVE requires releasedAt=null and releasedBy=null.
- RELEASED requires releasedAt integer >= acquiredAt and releasedBy populated.
- EXPIRED is a durable historical state only when explicitly projected; normal eligibility also treats ACTIVE with caller nowMs >= expiresAt as expired/denied.
- evaluator uses caller-supplied nowMs only; no wall-clock reads.

D. LEASE USE EVALUATOR
Add a pure deterministic evaluator for a proposed shared-state mutation.

Require:
- valid supported MUTATION_LEASE record;
- state ACTIVE;
- nowMs < expiresAt;
- expected project exact;
- expected holder registrationId/role exact;
- expected messageId/dispatchId/milestoneId exact;
- requested mutationEnvelopeSha256 exact;
- requested resource scope equal to or narrower than the authorized lease scope under one explicitly implemented deterministic rule;
- no active conflicting lease in caller-supplied competingLeases for overlapping governed resource scope.

At minimum outcomes/reasons must distinguish:
- MUTATION_LEASE_AUTHORIZED
- MUTATION_LEASE_INVALID
- MUTATION_LEASE_PROJECT_MISMATCH
- MUTATION_LEASE_HOLDER_MISMATCH
- MUTATION_LEASE_LINEAGE_MISMATCH
- MUTATION_LEASE_RESOURCE_SCOPE_MISMATCH
- MUTATION_LEASE_MUTATION_ENVELOPE_MISMATCH
- MUTATION_LEASE_EXPIRED
- MUTATION_LEASE_RELEASED
- MUTATION_LEASE_CONFLICT

No denied outcome grants retry or mutation authority.

E. CONFLICT RULE
Conflict detection is caller-bounded and pure:
- compare only caller-supplied competingLeases;
- a competing lease conflicts only when it is valid for the same project, ACTIVE at nowMs, held by a different leaseId/holder lineage, and its bounded resource scope overlaps the requested governed resource scope;
- released/expired/non-overlapping leases do not conflict;
- malformed competing records fail closed rather than being silently ignored when they claim the same project/resource domain.

Do not scan filesystem/network/GitHub/process state inside the evaluator.

F. IMMUTABLE RELEASE PROJECTION
Add a pure deterministic release projection that derives a new immutable revision only from an ACTIVE valid lease and exact caller release context.

The derived record must:
- preserve leaseId/epoch/project/resource scope/envelope/holder/message/dispatch/milestone/acquiredAt/expiresAt;
- increment leaseRevision exactly +1;
- require caller previousRecordSha256 lowercase 64-hex;
- set previousRecordSha256 to that caller value;
- set state RELEASED;
- set releasedAt to caller-supplied nowMs with acquiredAt <= nowMs <= expiresAt;
- populate releasedBy with exact registrationId, workerRole, messageId, dispatchId, milestoneId, and result/operation reference;
- remain independent/frozen-safe;
- never mutate/rewrite the prior record.

This milestone creates no live lease record.

PRE-DISPATCH VALIDATOR INTEGRATION

G. LEASE GATE

- mutationLeaseState=NOT_REQUIRED.
