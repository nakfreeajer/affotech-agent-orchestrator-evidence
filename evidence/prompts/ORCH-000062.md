B. COMMON PROJECT EVENT RECORDER
Add:

- test/project-event-recorder.test.js

Expose a factory such as createProjectEventRecorder(options).

Require explicit:
- projectId
- accepted project-event builder/validator
- accepted authoritative-event adapters or injected equivalent
- accepted GitHub event-ledger port or injected equivalent.

No IO/network/timer/process loop/write on import.

Provide recordAuthoritativeEvent(request).

Algorithm:
1. validate structured source record and requested producer family;
2. adapt it deterministically to an accepted project-event input;
3. require exact producerEventKey and durable details identity;
4. call the accepted ledger publishEvent exactly once;
5. normalize ledger outcomes without changing semantics;
6. return RECORDED only for durable PUBLISHED/PUBLISHED_RECONCILED exact event identity;
7. return ALREADY_RECORDED only when the canonical chain proves exact idempotent producerEventKey+payload identity;
8. return AMBIGUOUS with reconciliation descriptor when ledger is ambiguous;
9. return CONFLICT for incompatible canonical producer identity;
10. never retry in the same call.

Provide reconcileAuthoritativeEvent(request) read-only by delegating only to the accepted ledger reconciliation contract and verifying the returned canonical event still matches the source/adapted identity.

Provide recordSequentialBatch(requests, options) for bounded catch-up/integration:
- sequential single-flight only;
- preserve caller order;
- each input independently validates producer ownership;
- stop immediately on AMBIGUOUS, CONFLICT, invalid input or non-recorded outcome;
- never parallelize CAS publications;
- never skip a failed item and continue;
- return exact completed prefix and stop reason;
- no hidden retry.

C. PRODUCER OWNERSHIP / NON-REWRITING RULE
The recorder/adapters MUST enforce:
- Architect may publish Architect/human-promoted/accepted-source interpretation events, but may not author Executor execution facts.
- Executor may publish only first-hand Executor execution/validation/blocker facts, not Architect decisions.
- Reconciliation component may publish only reconciliation facts it owns.
- Curator may publish only Curator processing/cursor facts it owns.
- infrastructure adapter may transport a structured first-hand record, but transport does not change producerRole.
- a generic caller cannot set producerRole/eventType arbitrarily to bypass ownership.

D. EXACTLY-ONCE / IDEMPOTENCY
producerEventKey is the stable first-hand identity.
Exact duplicate structured source + exact adapted payload:
- may resolve idempotently only from canonical ledger proof.
Same producerEventKey with different payload/details hash/project/lineage:
- hard CONFLICT.
AMBIGUOUS:
- reconciliation only;
- no second publish in same call;
- no retry authority.
